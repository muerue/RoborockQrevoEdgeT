# Roborock Qrevo EdgeT – IP-Symcon-Modul

Das ZIP-Paket `RoborockQrevoEdgeT_IPSymcon.zip` enthält eine IP-Symcon-Bibliothek mit Modulmanifest, PHP-Modulklasse, Konfigurationsformular und Python-Brücke für `python-roborock`.

Siehe `RoborockQrevoEdgeT/README.md` für Installation, einmalige Roborock-Anmeldung, Konfiguration, Steuerungsfunktionen und Fehlerbehebung.

Das Paket wurde lokal auf JSON-, PHP- und Python-Syntax geprüft. Ein tatsächlicher Geräte- und IP-Symcon-Lauf muss auf deinem Zielsystem erfolgen.
